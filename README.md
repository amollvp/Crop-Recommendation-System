# 🌱 Crop Recommendation System

## 📌 Project Overview

The Crop Recommendation System is a Machine Learning application that recommends the most suitable crop based on soil nutrients and environmental conditions.

## 🚀 Features

- Predicts the best crop using Machine Learning
- Interactive Streamlit Web Application
- Data Visualization and EDA
- Random Forest Classifier
- High Prediction Accuracy

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- Joblib
